# 美术硬参数（唯一标准，写死不再改）

两个问题的答案都在这里。**尺寸和文件名以这张表为准**，代码里的常量就是从这张表来的。

## 一、尺寸怎么定

游戏格子 = **32×32 像素**，视口 1280×720。原则：

- **图块类**（能平铺的）：一律 **32×32**，四边必须能接上；
- **道具/机关**：按它在游戏里占的格子数出图（比如出口占 2×2 格 → 64×64）；
- **角色**：**64×64** 画布，人物占高度的 85% 左右（游戏里缩到 32px 显示）；
- **UI**：按屏幕上的实际像素出，不要放大 2 倍。

> 出图时**直接按表里的尺寸画**，不要画 512 再缩。像素感全靠这一步。

## 四、出图约定（复述一遍，避免再来回）

1. **直接按表里的尺寸画**，不放大不缩小；颜色 ≤32 种，硬边，无抗锯齿；
2. 背景：**发光物 / 紫色物 / 深色物 → 纯黑底**；**实心不透明物 → 透明底**；
   只有"身上没有紫色、也不是发光物的实心件"才可以用品红底（而且必须无柔光、无阴影）；
3. 平铺类（墙/地/砖/藤/加速带/软垫/栏杆/地板）：**四边必须接得上**；
4. 文件名、子目录**一字不改**，改了代码就找不到了。
