# 美术需求

v1 · 2026-10-29，11-02 加了终章用到的几样（优先级 3 的表）。现在画面全是代码画的占位，下面每一项都能一直用占位，做不出来也不影响进度。做好一项就放进对应目录告诉我，我来接进游戏、调大小和颜色。

## 通用规格

- PNG，透明背景。
- 按游戏里尺寸的 **2 倍** 画（表里写的是游戏里的尺寸）。画面会随窗口放大，2 倍图在 1080p、1440p 上都清楚。
- 画面是暗的：除了自己发光的东西，其他东西只有被小星的光照到时才看得见，照到时偏暖黄色。所以：
  - **被照亮的部分**（小人身体、影藤、地面）按正常颜色画，偏浅、偏中性，暖光照上去才好看。
  - **自己发光的部分**（灯、光晕、发光的纹路）单独出一张图，文件名加 `_glow`。白色或接近白色最好，颜色我在代码里调；想要固定颜色也可以直接画成那个颜色。
- 动画帧单独存，文件名后面加 `_0`、`_1`……，每帧画布一样大，中心对齐。8–12 帧/秒的感觉就够。
- 放在 `assets/art/<类别>/` 下，文件名用英文小写和下划线。
- 现在的配色参考：背景深蓝 `#070b18`，光 `#ffd75a`，小人 `#e8ecff`，影藤 `#6a3d8f`（烧的时候 `#ff8a3d`），玻璃 `#9fd8ff`，虫洞 `#b48cff`，检查点未点亮 `#8fb4ff`。

## 优先级 1：最影响观感

| 东西 | 游戏里尺寸 | 要什么 | 放哪 |
|---|---|---|---|
| 小人 ×12 个职业 | 约 20×28（画布 24×32） | 职业、照亮前的处境和浮现的梦想见 `docs/level-data-format.md` 第 7 节的表。每人三张：**照亮前**（失去希望的姿势，2 帧轻微抖动）、**照亮后**（实现梦想的姿势，1–2 帧）、**浮现画面**（梦想化成的发光图，比如守夜人身后的整条街灯，约 96×64，整张算发光图，发光剪影就够）。白色或浅灰的剪影，小尺寸下也认得出职业 | `assets/art/npc/`，例如 `watchman_before_0.png`、`watchman_after_0.png`、`watchman_dream.png` |
| 地面 | 平铺，单块 256×256 | 无光之城的地面（石板路、旧砖、裂开的柏油都行）。中性的灰米色、对比度低，上面的东西要看得清。要能无缝平铺 | `assets/art/ground/` |

## 优先级 3：可以一直用占位

| 东西 | 游戏里尺寸 | 要什么 |
|---|---|---|
| 小星（玩家） | 约 28×28 | 现在是会转的五角星，阶段 2 闪红出裂纹。想给它加表情的话：星体（不转）+ 普通、害怕（阶段 2）、困（亮度低）三种表情 |
| 裂纹墙 | 可平铺，64×64 | 深色墙体一张；裂缝单独一张 `_glow` |
| 玻璃 | 厚 8，长度不定 | 沿长边平铺的玻璃条，淡蓝、带高光 |

| 隧道支架 | 宽 64 一段，可平铺 | 矿工挖开的隧道上下两边的木撑子，暖棕色，算发光图 |
| 逃离点 | 64×160 | 终章终点的光门，黎明的颜色，整张发光，2–4 帧流动 |
| 电灯泡设计图 | 约 200×200 | 隐藏结局里噬光者体内找到的设计图：蓝色线稿的电灯泡，带尺寸线和标注，透明底。小星会摆在灯泡中间当灯丝 |
| 标题字 | 约 800×300 | 《星愿：撞碎长夜》标题字，透明底 |

普通黑墙不用画：墙会挡光，永远在阴影里，画了也看不见。

终章路边帮忙的人不用另画：用小人"照亮后"的图和浮现画面。
