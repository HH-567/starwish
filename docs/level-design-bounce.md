# 关卡设计稿：反弹小谜题 + 房间用途表

## 一、反弹小谜题（需求 5）

### 定稿规则（2026-11-08 按反馈改）

**不改软垫行为**。谜题只用**普通墙**：普通墙在阶段 3 以上是"反弹"（不扣血、保速），
所以只要房间让玩家能到**阶段 3**，撞墙弹回来、再加速冲过去，自然就上**阶段 4**，
正好够撞碎裂纹墙。

### 已经验证过的事

`tools/probe_bounce.gd` 在 **ch3 第一面裂纹墙前的房间**做过实测：

```text
从墙左边 9 格、阶段 3（500）出发，按住右 →
墙还在=false（撞碎了），最高阶段=4
```

也就是说**机制本身是通的**，不需要改软垫、也不需要改墙的弹性。
现在缺的不是机制，是**一个把它讲清楚的房间**：

- 现有房间有 17 格宽，玩家还没意识到"弹"就已经撞碎了，等于白送；
- 需要一个**窄房间**（5–6 格宽），直冲只能到阶段 3 → 撞墙弹回 → 回来刚好阶段 4。
  这样"弹一下"才是玩家自己发现的。

### 房间形状（待落地）

```text
   ┌─────────────────┐
   │                 │   普通墙（不是软垫）
   │   ┌─────────┐   │
   │   │         │ C │   C = 裂纹墙，堵住唯一出口
   │   │         │ C │
   │   └─────────┘   │
   └───────┬─────────┘
           │ 入口（从下面进，速度已经在阶段 2–3）
```

- 房间宽 **5–6 格**（160–192px），直冲（不弹）到墙前只有阶段 3；
- 撞墙 → 反弹 → 反向加速这一段刚好把速度顶过 620（阶段 4）；
- 出口在裂纹墙后面，不碎就过不去；
- **不用软垫**，普通墙就够。

### 验收标准（会写成测试）

1. 从入口以段速 3 直冲裂纹墙：**墙不碎**；
2. 撞墙反弹、不松手：**能到阶段 4**；
3. 阶段 4 撞裂纹墙：**墙碎、能通过**；
4. 阶段 1–2 撞墙：仍然是扣血（不反弹），和现在一致。

## 二、房间用途表（需求 6）

原则：**每个房间必须能一句话说出"玩家为什么进来"**。四类用途：

- **通路**：只有一条动线，不拐弯就出不去（走廊、竖井）
- **补给**：有小星星，进房间是为了续命
- **救人**：有小人在里面，进房间是为了带他走
- **机关**：有谜题（镜面反射、影藤燃烧、裂纹墙、虫洞），进房间是为了破它

过一遍现有五章的清单会太长，我先给**判定标准 + 处理办法**，你给我方向我就照这个标准量一遍：

| 情况 | 判定 | 处理 |
|---|---|---|
| 房间只有 3 格、进出同一个口 | 纯装饰 | 要么删掉、要么塞一颗小星星变成"补给" |
| 房间有 6 格以上空地但没任何东西 | **意义不明** | 加一颗小星星 / 放一个小人 / 放一个机关，三者选一 |
| 走廊长度 > 12 格且没有拐弯、没有机关 | 拉时长的水 | 截短，或者中间插一个拐角（顺便当加速直道用） |
| 房间里有实体但玩家不会主动靠近（比如贴在死角的灯） | 摆错位置 | 挪到动线上，或者删掉 |
| 房间有多个出口但都通同一个地方 | 冗余 | 封掉一个，避免玩家来回犹豫 |
