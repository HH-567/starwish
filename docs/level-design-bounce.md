# 关卡设计稿：反弹小谜题 + 房间用途表

## 一、反弹小谜题（需求 5）

### 要教的东西
**阶段 3 还撞不碎裂纹墙，得靠软垫反弹把速度顶到阶段 4。**

玩家现在的认知是"一直加速就能更快"。这个谜题反过来：**空间太小，直着冲不起来，必须借反弹**。

### 房间形状

```text
   ┌─────────────────────┐
   │ P                 P │   P = 软垫（四周全包）
   │                     │
   │   ┌───┐   ┌───┐     │   ┌┐ = 裂纹墙（只有中间这块要碎）
   │   │   │ C │   │     │
   │   └───┘   └───┘     │
   │                     │
   │ P                 P │
   └───────┬─────────────┘
           │ 入口（唯一开口，从下面进来）
```

- 房间 **7 格宽 × 5 格高**（224×160 像素），比玩家"起速需要的距离"短一半；
- 四角各一块软垫，中间一道裂纹墙（1 格厚，占满整个门洞）；
- 入口在正下方，出口在裂纹墙后面——**不碎墙就过不去**。

### 玩家会怎么试

| 尝试 | 结果 |
|---|---|
| 直冲裂缝 | 撞上弹回（速度 500 左右，阶段 3，碎不了）→ **学到"不够快"** |
| 撞墙弹回来，再撞对面软垫 | 每次反弹保留大部分速度，来回一趟速度叠上去 |
| 到阶段 4 再撞裂缝 | 墙碎，过去 |

### 关键参数（要保证"两次反弹刚好够"）

- 房间长边 224px，玩家单程约 0.35 秒；
- 阶段 4 阈值 620，阶段 3 阈值 470；
- 软垫反弹**不损失速度**（现在是急停，这个谜题需要改成"弹回"）——
  **这是唯一需要改的机制**：软垫在阶段 3–4 时把玩家弹回去而不是停住；
  阶段 1–2 仍然急停（新手不会突然被弹飞）。

> 也就是说，这个谜题同时把"软垫"从纯障碍变成了"弹弓"，这是个小机制升级，
> 我觉得值得做——它让阶段 3 这个平时"不上不下"的档位有了专门用途。

### 摆在哪一章

放 **ch3（裂纹墙章）** 的中段，作为"裂纹墙"机制的正式教学；前面的房间给一个
"够长直道 + 撞碎一面墙"的简单版本，这里给"弹不起来就过不去"的进阶版本。

### 验收标准（会写成测试）

1. 从入口以阶段 3 直冲裂缝：**墙不碎**，玩家被弹回；
2. 不操作（只借反弹）在房间里来回弹：**能到阶段 4**；
3. 阶段 4 撞裂缝：**墙碎、能通过**；
4. 阶段 1–2 撞软垫：**急停**（不会被弹飞）。

## 二、房间用途表（需求 6）

原则：**每个房间必须能一句话说出"玩家为什么进来"**。四类用途：

- **通路**：只有一条动线，不拐弯就出不去（走廊、竖井）
- **补给**：有小星星，进房间是为了续命
- **救人**：有小人在里面，进房间是为了带他走
- **机关**：有谜题（镜面反射、影藤燃烧、裂纹墙、虫洞），进房间是为了破它

过一遍现有五章的清单会太长，我先给**判定标准 + 处理办法**，你给我方向我就照这个标准量一遍：

| 情况 | 判定 | 处理 |
|---|---|---|
| 房间只有 3 格、进出同一个口 | 纯装饰 | 要么删掉、要么塞一颗小星星变成"补给" |
| 房间有 6 格以上空地但没任何东西 | **意义不明** | 加一颗小星星 / 放一个小人 / 放一个机关，三者选一 |
| 走廊长度 > 12 格且没有拐弯、没有机关 | 拉时长的水 | 截短，或者中间插一个拐角（顺便当加速直道用） |
| 房间里有实体但玩家不会主动靠近（比如贴在死角的灯） | 摆错位置 | 挪到动线上，或者删掉 |
| 房间有多个出口但都通同一个地方 | 冗余 | 封掉一个，避免玩家来回犹豫 |
