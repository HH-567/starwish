# 美术资源需求（星愿：撞碎长夜）

现在整个游戏**没有一张位图**：所有东西都是 `_draw()` 里用几何图形和颜色画出来的（`docs/level-data-format.md` 第 4 节、各实体脚本）。这份清单就是把这些程序图形逐项换成美术图的清单，代码按实体粒度接图，可以一张一张上，不影响已完成的玩法。

## 1. 统一规格

| 项 | 要求 |
|---|---|
| 分辨率 | 视口 1280×720，格子 32 px。角色和实体按 32 的倍数出图，建议出 2 倍（64/128）再缩 |
| 格式 | PNG-24 + Alpha，**不要预乘**，导出时别裁边 |
| 光晕 | 不要画进资源本体（引擎里用加法叠加），只有标了「含发光」的才画 |
| 中心 | 图形放在画布正中；物理判定由代码给（圆/矩形），美术只管视觉 |
| 动画 | 横排 sprite sheet 或逐帧单图都行，请在交付时注明帧尺寸和帧数 |
| 命名 | `assets/art/<类别>/<名字>_<变体>.png`，如 `characters/npc_watchman_idle.png` |
| 交付 | 原文件 + 一层 PSD/ASE 分层文件（方便后面微调），放到仓库 `assets/art/` 下 |

## 4. 怎么接进游戏

1. 把图放进 `assets/art/<类别>/`，文件名按上表；
2. 首次导入后跑一次 `godot --headless --path . --import`（项目里资源有 .import/.uid 缓存）；
3. 我在对应实体的 `_ready()` 里加一个 `Sprite2D`（或 `AnimatedSprite2D`），原来 `_draw()` 的几何图形保留作为**缺图时的兜底**——这样没图也能跑；
4. 光照相关：所有实体都在 `Lighting.unshaded()` 下画，接图后同样保持不变，否则暗处会看不见。

- 每一项交付后，我会在 `docs/shots/` 里截一张游戏内实拍做对照（暗处、满亮度、低亮度各一张）；
- 有自动化测试覆盖的部件（玩家、小人、机关、影鬼、弹幕、Boss、UI）改图后必须仍跑通那 21 项测试；
- 尺寸不符或中心偏移的，我先在实体里加偏移量，不要求美术返工。

## 6. 可以不做的东西

- 背景视差、标题插画、字体都是 **P2/P1**：没有它们游戏也能完整玩，先把 P0 的 30 来张做完就够上线。
- 现有几何画法本身是能看的（截图见 `docs/shots/`），所以这份清单是「替换」，不是「补缺」。
