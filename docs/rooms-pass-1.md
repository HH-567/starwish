# 房间用途巡检（第一遍）

按"每个房间要能一句话说清玩家为什么进来"这条标准，把五张地图切成"偏离主路线的区域"逐个检查。
方法：先算出生点→出口的最短路，再算每个可走格子到这条路的格数；**离路线 ≥2 格**、
且连通成片（≥4 格）的区域就是"玩家不一定会去的地方"。

## 结果

| 章 | 主路线 | 偏离区域 | 其中全空的 |
|---|---|---|---|
| ch0 | 128 格 | 12 块 | 3 块（52 / 46 / 9 格） |
| ch1 | 243 格 | 11 块 | 1 块（38 格） |
| ch2 | 特殊（靠虫洞过墙） | 1 块 | 0 |
| ch3 | 255 格 | 8 块 | 3 块（20 / 11 / 5 格） |
| ch4 | 205 格 | 8 块 | 2 块（24 / 11 格） |

## 这一遍做了什么

只做**最保守的一步**：全空且 ≥4 格的地方，补一颗小星星（补给），让它至少有"进去的理由"。

| 章 | 加星星的位置 |
|---|---|
| ch0 | (70,24)、(60,24)、(20,16) —— 51..89 × 23..25 那块空房、17..30 × 9..17 那块空房 |
| ch1 | (87,17) —— 79..96 × 13..22 的空房 |
| ch3 | (91,22)、(65,23) —— 两处死胡同 |
| ch4 | (144,22)、(62,24) —— 两处细长空走道 |

**没有删任何房间**：删掉会让地图变小、路线变短，风险比补内容大。

## 第二遍：把 ch4 的大空厅切成街区

用"宽格"（九宫格几乎全空的可走格）来量**房间**而不是走廊，结果 ch4 最糟：

| 章 | 最大的三个房间（宽格数） |
|---|---|
| ch0 | 133 / 44 / 44（都有内容） |
| ch1 | 522 / 106 / 105 |
| ch2 | 1023 / 91 / 27 |
| ch3 | 498 / 240 |
| **ch4** | **505 / 300 / 294 —— 三个厅加起来 1100 格宽，里面只有 5 颗星星** |

ch4 是"城市中心"，三个空厅既不像城市也没有内容。改法：在厅里**砌街区**
（3×7 到 4×3 的墙块，交错摆放），街道留 2 格宽：

| 厅 | 加了什么 | 结果 |
|---|---|---|
| (57,11)-(127,23) | 4 块街区，上下交错 | 505 → **395** 宽格 |
| (128,9)-(159,21) | 2 块 | 300 → **236** |
| (160,1)-(187,13) | 2 块 | 294 → **220** |

效果：

- 空厅变成"有拐弯的街道"，路过要转向 → 和"城市"的主题对上了；
- 顺带增加了转向，玩家在城里不可能一直直线冲；
- 全部测试通过（`test_ch4` 的通行路线没被切断）。

## 第三遍：ch1 三个一模一样的房间改成三种机关

ch1 那三个房间原本是**复制粘贴**的：每个都是 2 星 + 5 面天花板镜子 + 两根柱子。

| 房间 | 原来 | 改成 | 玩家进去学到什么 |
|---|---|---|---|
| A（x≈136） | 天花板 5 面镜子 | 保留镜子，房里再补一对**斜镜** `/` `\` 成 V 形 | 反射可以拐两次弯 |
| B（x≈169） | 天花板 5 面镜子 | 换成 **5 格影藤** | 头顶是藤，得烧穿才亮 |
| C（x≈201） | 天花板 5 面镜子 | 换成**向上的加速带**，地板尽头加 **3 格软垫** | 快进 + 急停，学会控速 |

三个房间现在从俯视图上看颜色就不一样（蓝 / 紫 / 金），玩起来也是三种手感。

## 还剩下的问题（下一遍要处理）

1. **大空房只靠一颗星星还是空**：ch0 那块 52 格、ch1 那块 38 格，进去一颗星就出来，
   仍然"意义不明"。下一遍要给它**第二个用途**：
   - 放一个可救的小人（需要新的职业位置），或
   - 放一个机关（影藤 / 裂纹墙 / 镜子），或
   - **用墙把它切小**，变成 2–3 个有明确用途的小空间。
2. **细长空走道**（ch3 的 5 格、ch4 的 11 格）：直接**封死**比塞东西更干净。
3. **ch2 的路线分析失效**：那一章的出口在墙后，主路线要经过虫洞，
   用"最短路"量出来只有 1 格。下一遍改成"经过虫洞的两段路"分别算。

## 判定标准（复述，后续按这个执行）

| 情况 | 处理 |
|---|---|
| 全空、≥4 格、不在动线上 | 补星星 / 加小人 / 加机关，三选一 |
| 全空、<4 格（细缝） | 封死 |
| 有东西但玩家不会路过 | 把东西挪到动线上 |
| 多个出口通同一处 | 封掉一个 |
| 走廊 >12 格无拐弯无机关 | 截短或中间加拐角 |
