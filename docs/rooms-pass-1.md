# 房间用途巡检（第一遍）

按"每个房间要能一句话说清玩家为什么进来"这条标准，把五张地图切成"偏离主路线的区域"逐个检查。
方法：先算出生点→出口的最短路，再算每个可走格子到这条路的格数；**离路线 ≥2 格**、
且连通成片（≥4 格）的区域就是"玩家不一定会去的地方"。

## 结果

| 章 | 主路线 | 偏离区域 | 其中全空的 |
|---|---|---|---|
| ch0 | 128 格 | 12 块 | 3 块（52 / 46 / 9 格） |
| ch1 | 243 格 | 11 块 | 1 块（38 格） |
| ch2 | 特殊（靠虫洞过墙） | 1 块 | 0 |
| ch3 | 255 格 | 8 块 | 3 块（20 / 11 / 5 格） |
| ch4 | 205 格 | 8 块 | 2 块（24 / 11 格） |

## 这一遍做了什么

只做**最保守的一步**：全空且 ≥4 格的地方，补一颗小星星（补给），让它至少有"进去的理由"。

| 章 | 加星星的位置 |
|---|---|
| ch0 | (70,24)、(60,24)、(20,16) —— 51..89 × 23..25 那块空房、17..30 × 9..17 那块空房 |
| ch1 | (87,17) —— 79..96 × 13..22 的空房 |
| ch3 | (91,22)、(65,23) —— 两处死胡同 |
| ch4 | (144,22)、(62,24) —— 两处细长空走道 |

**没有删任何房间**：删掉会让地图变小、路线变短，风险比补内容大。

## 还剩下的问题（下一遍要处理）

1. **大空房只靠一颗星星还是空**：ch0 那块 52 格、ch1 那块 38 格，进去一颗星就出来，
   仍然"意义不明"。下一遍要给它**第二个用途**：
   - 放一个可救的小人（需要新的职业位置），或
   - 放一个机关（影藤 / 裂纹墙 / 镜子），或
   - **用墙把它切小**，变成 2–3 个有明确用途的小空间。
2. **细长空走道**（ch3 的 5 格、ch4 的 11 格）：直接**封死**比塞东西更干净。
3. **ch2 的路线分析失效**：那一章的出口在墙后，主路线要经过虫洞，
   用"最短路"量出来只有 1 格。下一遍改成"经过虫洞的两段路"分别算。

## 判定标准（复述，后续按这个执行）

| 情况 | 处理 |
|---|---|
| 全空、≥4 格、不在动线上 | 补星星 / 加小人 / 加机关，三选一 |
| 全空、<4 格（细缝） | 封死 |
| 有东西但玩家不会路过 | 把东西挪到动线上 |
| 多个出口通同一处 | 封掉一个 |
| 走廊 >12 格无拐弯无机关 | 截短或中间加拐角 |
